# Mindween Website

A minimal, responsive one-page company website for Mindween.

## Files
- index.html
- styles.css
- script.js

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
1. Confirm the contact email `hello@mindween.com` exists. If not, replace it.
2. Replace the simple "M" brand mark with your final logo when available.
3. Add legal/privacy pages if you collect visitor information.
4. Deploy the three files to mindween.com using your hosting provider.

## Suggested tagline
Primary: **to think beyond!**

This keeps your original idea, but the site uses "Think beyond" as a shorter visual expression in a few places.
